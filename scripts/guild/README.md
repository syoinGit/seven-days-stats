# ギルドのSDキャラクター

街・一覧・住人詳細・ダンジョンは、共通の `fragments/guild :: sprite(c)` または `figure(c, pose)` で96×144のSDを描画する。会話プレーヤーも同じSDをカウンター越しに大きく出す。ラスター画像や画像生成APIは使わない。

## 素材を編集する

形状の編集元は `scripts/guild/generate-people.py`。髪、服、道具、帽子、装飾品を曲線で定義している。

```sh
python3 scripts/guild/generate-people.py
python3 scripts/guild/preview-people.py
python3 -m http.server 18765 --bind 127.0.0.1 --directory target/guild-sd-preview
```

変更前と同じキャラを並べて確認する場合は `python3 scripts/guild/preview-people.py --compare-ref <変更前のコミット>` を使う。指定したGitリビジョンのSVGを比較用に取り出すだけで、作業中の素材や保存データは変更しない。

`http://127.0.0.1:18765` で目9種類・眉3種類・髪45種類・衣装72パターンを比較できる。同じパーツを大きいサイズと街・一覧のサイズで表示する。プレビューは架空の組み合わせであり、DBには接続しない。生成した `src/main/resources/static/img/guild-people.svg` もソース管理する。素材を更新したらテンプレートのSVG URLのバージョンを上げ、キャッシュを更新する。

## 既存の住人との互換性

既存のパーツIDと `--skin` / `--hair` / `--cloth` / `--cloth2` / `--eye` を維持する。髪・服・配色・装飾品と、目の形・眉の形・衣装差分はDBに保存した値を利用する。ページ表示では再抽選しない。古い住人や無効な外見データには `resident` のSD素材を使い、従来のappearanceの色を残す。V70で `eye_style` / `brow_style` / `outfit_variant` を追加する。既存のレイヤー式住人にはIDをもとに目9種類・眉3種類を一度だけ割り当てる。髪・色・衣装はそのまま。以後の変更は明示的な再調整時だけ。

SDの各symbolと共通テンプレートは `viewBox="0 0 96 144"` を使用する。パーツを改名・削除する場合は保存データへの対応が必要。輪郭線も拡大するため `non-scaling-stroke` は使わない。

## 輪郭・ポーズ

顔の輪郭は、柔らかい・丸い・顎がはっきりした形の3種類。住人IDから固定して選ぶため、ページごとに変わらない。DBに新しい列は追加しない。

ポーズは `rest`（通常）、`wave`（手を振る）、`crossed`（腕組み）、`mug`（カップを持つ）、`think`（考える）の5種類。SDではポーズ時の体・衣装をクリップし、通常の腕や横に持つ道具が二重に残らないようにする。袖と腕は職業別に用意し、肌・衣装の色を引き継ぐ。街ではその時間の行動文を優先し、それ以外は性格文を手掛かりに選ぶ。

## 線・光・素材の仕上げ

肌・髪・布・革・金属・金には、それぞれ異なる陰影を重ねる。元の色を下地に残し、透明な光と影を載せるため、住人ごとの保存済みの配色を引き継ぐ。肌の光は顔と口元で同じ座標系を使い、表情を重ねても色の境目が出ないようにする。

髪は輪郭に沿って毛束の線・光・影を描き、クリップで顔の開口部にはみ出さないようにする。目はまぶたの形に合わせた先細りのまつ毛、瞳の上下の陰影、同じ方向からの反射光を使う。布には折り目と裾、革には縫い目、金属には強い反射と刃の面取りを加える。

光と影はSVGだけで描画し、ぼかしフィルターや追加画像の読込は使わない。共通の仕上げ定義とパーツ内のクリップIDはSVG全体で一意にする。旧データ用の `resident` にコピーするクリップIDには専用の接頭辞を付ける。

## 人物らしさ

職業ごとに、鎧と盾、作業用エプロンとハンマー、本と鞄、弓、調理道具などを描き分ける。髪型は15→45種類（男性21・女性24）。衣装は職業・性別ごとの24種類に「普段着・旅装・晴れ着」の3差分を用意し、合計72パターン。目は丸目・アーモンド・たれ目・つり目・半目・ぱっちり・細目・きらめき・笑い目の9種類。眉は自然・直線・アーチの3種類。色だけでなく輪郭や前髪、まぶた、瞳の大きさなどを変えている。

年齢が20歳未満ならそばかす、40歳以上なら控えめな顔の線、60歳以上ならしわを重ねる。年齢不明の場合は追加しない。

性格文に含まれる日本語の手掛かりから、明るい・意志の強い・思慮深い・穏やかな基本表情を選ぶ。複数が一致した場合は `GuildPeople.expression()` の順に優先し、該当しない場合は通常の顔を使う。これは簡易的な文言一致で、否定や複雑な文脈の解析はしない。会話中の感情推定や表情アニメーションではなく、人物の基本表情。追加のAI呼び出しはない。

目→性別の顔の補助→眉→基本表情→年齢の順で、表情は口元だけを変更する。

表情と年齢のレイヤーは髪・装飾品・帽子より前に置き、眼鏡やひげなどを上書きしない。

## メンテからの再調整

住人の現在の外見と「目元を引き直す」「外見を引き直す」を表示する。目元は目と眉の形だけを変え、瞳の色や髪・服は維持する。外見は髪・髪色・服の配色・衣装差分・小物・瞳の色・目元を選び直し、肌の色を保つ。どちらも現在と異なる目の形を選び、外見の場合は髪型も変える。選択結果は即時保存し、その住人の位置に戻る。

名前・年齢・性別・職業・性格・記憶・交流履歴は変更しない。AIは呼ばず、管理者権限とCSRFが必要なPOSTだけで更新する。旧データで外見パーツがない場合は、最初の再調整で外見を設定する。

## 確認

```sh
./mvnw -Dtest=GuildTests,GuildAppearanceTests test
```

パーツの存在、座標系、年齢・性格のレイヤー順、旧データ、各ページのテンプレート描画を確認する。ブラウザでは特に32×48の一覧表示、会話でのSDの拡大表示、帽子と髪の重なり、スマホでの見切れを確認する。
